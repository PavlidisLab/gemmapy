## Why

swagger-codegen v3's Python generator cannot express a response-level
`oneOf`. It emits an empty `InlineResponseNNN` model, which makes the raw
SDK return a plain dict and breaks every `ps.process_*(response.data)` call
in the wrapper. Endpoints that also lost their parameterized response
container are re-typed, because an untyped `data` payload deserializes to
raw camelCase dicts that the snake_case processors silently read as NaN.
